# Step 40 — gesture speed options (2026-10-11)

## Why (findings, no measurements)
- Jieshuo recognises swipes with the Android system `onGesture` (no own matcher). This fork runs every touch through its own matchers (Swipe, MultiTap, MultiTapAndHold in utils/gestures): swipe needs 1.0 cm, "and hold" waits the full system long-press time.
- Both services use notificationTimeout=0 and similar flags, so the service config is not the difference.
- Jieshuo and this app both use the system long-press timeout for the hold gesture.
- Our own code added fixed waits: service-made long press = system long-press + 150 ms; after a scroll the new content is read only after 600 ms (MsReadingExtras.afterScroll).
- Scroll up/down call the app's own scroll action, so the scroll distance and speed belong to the app.

## Done (Settings > Operation > Gestures, end of the screen; defaults unchanged)
- `ms_gesture_swipe_cm`: swipe length 1.0 / 0.8 / 0.6 / 0.5 cm. Swipe time limits scale with the length, so the required finger speed stays the same. Applies after TalkBack is restarted (read when the gesture matchers are created).
- `ms_gesture_hold_percent`: double-tap-and-hold hold time 100 / 80 / 65 / 50 % of the phone's touch-and-hold delay (never below 40 % or 100 ms). Applies after restart.
- `ms_gesture_long_click_extra`: extra hold of service/command/script long presses 150 / 80 / 40 ms. Applies at once.
- `ms_scroll_read_delay`: wait before reading after a scroll 600 / 400 / 250 ms. Applies at once.
- Code: GestureConfiguration (swipeConfirmCm, holdPercent, longPressTimeoutMs), GestureMatcher, Swipe, GestureManifold.loadMsGestureSpeed, new editor/MsGestureTiming, MsReadingExtras, LuaServiceApi/JxCommands long-click callers.
- ms_jx_op_default_gesture_setting.xml is generated by devtools/step19_gen/gen_settings.py: re-running that script would remove the four new entries; add them to the generator before re-running.

## Suggested first try (to be tested on the phone)
Swipe 0.6 cm, hold 65 %, long-click extra 80 ms, scroll wait 400 ms. If gestures start to trigger by accident, go back one step.
