Or paste text instead of choosing a file


Paste any text here. If it contains === FILE: path === markers (like the text dump this tool's companion chat can generate for a whole project), it is split automatically into all of those files in one upload. Otherwise it uploads as a single file — enter a path for it below first.












Or fetch a whole project/ZIP from a link


Best effort — this only works for links that allow being fetched from a browser page (for example GitHub's own "raw" file links). Most ordinary web pages, Google Drive, and Dropbox links block this (a CORS restriction the site itself enforces, not a bug here) — if it fails, use "paste text" or "Upload files" above instead. If the link ends in .zip, it is automatically unpacked into its individual files, exactly like uploading a ZIP above.










Or add the Android build workflow with one tap


Most Android projects don't come with a GitHub Actions workflow file, so "Start APK build" below has nothing to run until one exists. This creates .github/workflows/build.yml for you — a standard debug-APK build using JDK 17 and Gradle 8.13 — with a single tap. Safe to tap again later; it will just update the file.

    Build APK
    

    The build still runs on GitHub Actions, but you control it from here. The workflow file is detected automatically from .github/workflows — you do not need to name it a specific way. If there is more than one, you will be asked which to run. Once a build starts, this page checks its progress automatically every few seconds and announces success or failure — you don't need to tap anything else. If it fails, the errors are read and copied to your clipboard automatically.

    Upload a large file (up to 2 GB, e.g. a big APK)
    

    Normal uploads above are limited to 100 MB (a GitHub limit, not this tool's). For anything bigger, this uploads it as a GitHub "Release" file instead, which allows up to 2 GB. It can take a few minutes on mobile data — stay on this page until it says done. When it finishes, the link below is filled in automatically for the Decompile section further down. Note: if this repository is public (the default when created with this tool), the uploaded file becomes downloadable by anyone with its link — don't upload anything private this way.

    Decompile an APK (get readable Java-like source code)
    

    Use ONE of the two boxes below, not both — whichever matches how you added the .apk. Small file (under 100 MB) uploaded with "Upload files" above: put its repository path in the first box, e.g. app.apk. Large file (100 MB–2 GB) uploaded just above as a Release: the link box below fills in automatically — leave the first box empty. Then tap "Start Decompile". GitHub Actions runs jadx and packages the whole result into one ZIP, downloadable in a single tap below — not separate files.
